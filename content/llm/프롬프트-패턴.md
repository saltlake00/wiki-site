# 프롬프트 패턴

> **판단**: 실제로 정착한 건 위키 운용 프롬프트 3개("정리해줘" / "찾아줘" / "점검해줘")뿐이고, "일반 기법" 절은 만들어놓고 **비어 있다.**
> **다음**: "일반 기법"을 채우거나, 계속 비면 이 페이지를 **위키 운용 프롬프트 전용으로 좁힌다.** 빈 절을 방치하면 목차만 있고 내용은 없는 페이지가 된다.

LLM 사용 중 발견한 유용한 프롬프트/기법 모음. 자주 쓰는 것만 정리.

## 위키 구축/사용 프롬프트

- **"이 위키에 정리해줘"** — 자료(URL/파일/메모)를 주면 `raw/`에 저장하고 관련 페이지 생성
- **"위키에서 X 찾아줘"** — index.md → 관련 페이지 읽고 답변
- **"위키 점검해줘"** — lint: 중복/깨진 링크/오래된 내용 확인
