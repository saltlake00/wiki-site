# 2D 타일맵 (Tilemap)

> **판단**: 타일맵 작업의 실제 변수는 **Pixel Per Unit**과 **Rule Tile 규칙 설계** 둘로 몰린다. 나머지는 이 둘이 맞으면 대체로 따라온다. 규칙은 전부 만들 필요 없이 **필요한 것만** 만든다.
> **다음**: 없음 — 엔진 기능 참고용 정리다. 진행할 작업이 없어 `status: stable`로 내렸다.

> Unity 2D에서 맵을 만들 때 쓰는 타일맵 기능 정리. 3D와의 차이, 스프라이트, 픽셀 퍼 유닛, 룰 타일, 오버라이드 타일, 시네머신.

## 2D에서 눈에 보이는 것 = Sprite (3D는 Mesh)

- 3D 오브젝트는 **Mesh** 컴포넌트가 눈에 보이게 하는 역할을 합니다.
- 2D에서는 **Sprite Renderer**가 그 역할을 합니다.

| | 3D | 2D |
|---|---|---|
| 눈에 보이게 하는 것 | Mesh | Sprite Renderer |
| 앞뒤(가까움/먼) 결정 | 카메라와의 거리 | Sorting Order |

### Sorting Order
- 2D는 **Sorting Order** 값으로 앞뒤가 결정됩니다. 값이 클수록 앞(가까이)에 보입니다.
- **Sorting Layer**는 하이어라키에서 직접 추가해서 설정할 수 있습니다. "배경 레이어", "캐릭터 레이어"처럼 나눠 쓸 수 있습니다.

## Sprite 애니메이션
- 3D는 녹화 버튼(Record)으로 Transform 변경사항을 저장합니다.
- 2D도 같은 방식으로 저장할 수 있지만, **Sprite는 Transform만으로 움직이기 어렵습니다.**
- 그래서 **Sprite Renderer에 들어있는 Sprite 이미지를 교체**하는 방식으로 애니메이션을 만듭니다. 여러 장의 스프라이트를 순서대로 바꿔치기합니다.

## 타일맵(Tilemap) 만들기
- 스프라이트를 하나하나 배치하기 어려워서 타일맵을 사용합니다.

```
Grid (그리드 공간)
 └── Tilemap (타일맵)
      └── Tile Palette (타일 팔레트)
```

- **Grid**: 타일이 놓이는 격자 공간
- **Tilemap**: 그리드 아래에 타일을 그리는 레이어
- **Tile Palette**: 타일을 선택해서 그림 그리듯 배치하는 도구

### 사용법
1. **Tile Palette** 창을 열고 타일을 등록합니다.
2. 팔레트에서 타일을 선택하면 **브러시**처럼 그릴 수 있습니다.
3. **도화지(레이어)는 여러 장** 쓸 수 있습니다. 타일맵을 여러 개 만들어 겹쳐 씁니다.

## Pixel Per Unit (픽셀 퍼 유닛)
- **"한 유닛에 픽셀 몇 개를 쓸 것인가"**를 정하는 설정입니다.
- **64** 설정 → 64픽셀 이미지가 1유닛 크기로 보입니다.
- **백그라운드(배경)**는 보통 **256**을 설정합니다.

### 이미지 픽셀 크기 확인
1. 프로젝트 창 → **Show in Explorer** (파일 위치 열기)
2. 이미지 파일 → **속성 → 자세히** 탭
3. 몇 픽셀짜리 이미지인지 확인

> 예: 타일 이미지 64픽셀 → Pixel Per Unit 64, 배경 256픽셀 → 256.

### 정사각형이 아닌 타일
- Pixel Per Unit은 가로/세로를 따로 조정할 수 있습니다.
- **Grid 크기 자체를 조정**할 수도 있지만, Grid는 모든 타일이 공유하므로 주의해야 합니다.
- 정사각형/직사각형이 섞여 있으면 **이미지를 정사각형으로 맞추는 게 더 편합니다.**

## Rule Tile (룰 타일) — 자동으로 이어지는 타일
- 타일을 하나씩 클릭해서 그리면 "가운데/끝/모서리"를 매번 골라야 해서 귀찮습니다.
- **Rule Tile**은 **주변 타일 상태에 따라 자동으로 이미지를 선택**해줍니다. 땅 타일을 그리면 옆에 땅이 있으면 이어지고, 끝이면 끝 모양으로 자동 변환됩니다.

### 만드는 방법
1. 프로젝트 창 → **Create → 2D → Tiles → Rule Tile**
2. **Sprite**에 사용할 타일 이미지를 넣습니다.
3. 타일 팔레트에 등록합니다.

### 규칙(Rule) 설정
- 가운데 기준 **8방향(위/아래/왼쪽/오른쪽/대각선)**을 살펴봅니다.
- 각 방향에 타일이 있으면(연결되면) 그 이미지, 없으면 다른 이미지를 선택하도록 설정합니다.
- 예: 위쪽에만 연결 → 위로만 이어지는 이미지, 위아래로만 연결 → 세로로 이어지는 이미지.

### 필요한 규칙만 만들기
- 처음에 **9개(가운데 + 8방향)**로 시작해서 필요한 것만 3개씩 추가합니다.
- **절대 나오지 않을 형태의 규칙은 만들지 않습니다.** 불필요한 규칙은 오히려 헷갈리게 만듭니다.
- **대각선 규칙은 충돌 주의.** 위아래 규칙과 대각선 규칙이 겹치면 타일이 이상하게 나올 수 있습니다. 서로 충돌하지 않게 설정해야 합니다.

## Override Tile (오버라이드 타일)
- 기존에 만든 타일을 **덮어쓰는(변형하는) 타일**입니다.
- 기존 타일의 규칙을 그대로 쓰면서 **이미지만 바꿀 수 있습니다.**
- 예: 같은 땅 타일인데 색만 다른 버전.
- 타일 팔레트에 넣어서 사용합니다.

## 타일맵 콜라이더 (충돌)
- 타일맵에 **Tilemap Collider**를 추가하면 타일 모양대로 충돌 영역이 생깁니다.
- 캐릭터가 땅 위를 걷거나 벽에 막히는 등 **이동 기능**을 만들 때 필요합니다.

## Cinemachine (시네머신) 카메라
- 기본 카메라보다 강력한 **Cinemachine** 카메라 컴포넌트.
- **플레이어를 따라다니는 카메라**를 쉽게 만들 수 있습니다.
- 다양한 **임팩트(흔들림, 줌 등)** 효과.
- 기능이 많아서 **플랫폼 게임에서 가장 많이 쓰는 기능 위주**로 익힙니다.

## 바이브 코딩(Vibe Coding) 관점
- 유니티는 기능이 많아서 **"유니티 엔진에 이런 게 있다"** 정도만 기억하면 됩니다.
- 바이브 코딩으로 작업할 때 AI에게 "이거 어떻게 활용해?"라고 시키면서 AI가 쓰는 걸 보면서 익힙니다.
- **내가 알고 있으면 더 정확하게 지시할 수 있습니다.**
