# 링스택 vs 원본스택

> **판단**: 차별점은 한 줄로 요약된다 — **반지름이 불변이라 실패해도 실루엣이 원기둥으로 남는다.** 이게 이 프로젝트의 존재 이유고, 다른 차이(회전, 리빌 연출)는 여기서 파생된다.
> **다음**: 없음.

링 스택 게임이 원본 Stack 게임과 어떻게 다른지 비교.

## 비교표

| 구분 | 원본 Stack | 링 스택 |
|---|---|---|
| 블록 이동 | 좌우 왕복 | 중심축 기준 시계/반시계 교대 회전 |
| 어긋남 처리 | 좌우로 잘려나감 → 폭이 점점 좁아짐 | 원둘레 각도 단위로 잘려나감 → **폭(반지름)은 불변**, 이빨 패턴만 변화 |
| 실패 시 실루엣 | 위로 갈수록 뾰족한 피라미드 | 구멍이 뚫려도 옆에서 보면 여전히 원기둥 |
| 실패 조건 | 완전히 어긋나면 게임오버 | 동일 (겹치는 각도 합 = 0˚) |
| 게임오버 연출 | 그 자리에서 종료 | 붕괴 없이, 현재 상태 그대로 카메라 전체 줌아웃 리빌 |

## 핵심 차별점

- **판정과 실루엣 분리**: 안에서는 이빨이 깎이지만, 겉에서 보면 항상 같은 두께의 기둥.
- **바깥/안쪽 반지름 항상 고정**: 아무리 실수해도 실루엣은 늘 원기둥 유지.
