# 링 스택 (Ring Stack)

> 스택(Stack) 장르의 핵심 재미 — **타이밍 탭 + 정렬 판정** — 은 그대로 가져오면서,
> 실패가 쌓여도 위로 갈수록 뾰족해지는 피라미드가 아니라 **항상 일정한 굵기의 원기둥**을 유지하도록 재구성한 변형작입니다.

Unity(URP)로 제작. 본 저장소는 씬/프리팹/머티리얼을 코드로 전부 자동 생성하는 에디터 툴을 포함하고 있어, 메뉴 한 번으로 처음부터 플레이 가능한 상태를 다시 만들어낼 수 있습니다.

Unity MCP를 활용한 바이브 코딩(vibe coding)을 공부하는 목적으로 진행한 스택 게임 모작 프로젝트입니다.

> **크레딧**: "좌우 이동 대신 회전, 잘려도 원기둥 실루엣은 유지"라는 이 링 스택 컨셉 자체는 제가 직접 고안한 것이 아닙니다. Reddit 또는 YouTube에서 (정확한 출처는 기억이 나지 않습니다) 누군가 만든 작업물을 보고 인상 깊어서 비슷하게 따라 만들어본 것임을 밝힙니다. 원작자분께 감사드리며, 출처를 다시 찾게 되면 이 문서에 링크를 추가하겠습니다.

## 핵심 컨셉

원본 Stack이 좌우로 왕복하는 블록을 탭으로 멈춰 쌓는 게임이라면, 이 게임은 좌우 이동을 **회전**으로 바꿨습니다.

- 톱니(기어) 모양으로 뚫린 도넛형 링이 타워 축을 기준으로 시계 ↔ 반시계 방향을 층마다 교대하며 계속 회전합니다.
- 탭하면 그 순간 회전이 멈추고, **바로 아래층에 남아있는 살(rib) 패턴**과 **현재 이빨 패턴**을 겹쳐서 겹치는 부분만 살아남습니다.
- 원본처럼 어긋난 만큼 폭이 좁아지는 게 아니라, **바깥/안쪽 반지름은 항상 고정**된 채 원둘레 방향으로만 깎여나갑니다 — 그래서 아무리 실수해도 실루엣은 늘 원기둥을 유지하고, 옆에서 보면 어디가 잘렸는지 티가 잘 안 납니다.
- 완전히 겹치는 부분이 0이 되는 순간 게임오버. 무너지는 연출 없이, 카메라가 부드럽게 줌아웃/오빗하며 완성된 타워 전체를 리빌합니다.

## 주요 기능

- **판정 로직**: 원둘레를 720개 각도 슬롯으로 표현해 겹침을 AND 연산으로 계산 (`RingSlotUtil`).
- **낙하 링이 "마지막 층"을 참조**: 완벽한 타이밍으로 탭하면 전혀 깎이지 않고 그대로 유지되며, 어긋난 만큼만 자연스럽게 깎입니다. 10~16층마다 무작위로 새 이빨 패턴으로 리셋되어 계속 조금씩만 줄어들다 끝나지 않습니다.
- **판정 허용 오차**: 아주 작은 회전 오차(기본 2.5˚ 이내)는 완벽한 정렬로 봐줘서 손맛이 너무 빡빡하지 않게 조정.
- **절차적 메시 생성**: 이웃한 각도 분할과 정점을 공유하는 진짜 쐐기(부채꼴) 지오메트리로, 이음매 없이 매끈한 곡면 + 면 사이는 하드 엣지를 유지 (`GearRingMeshBuilder`).
- **커스텀 툰(NPR) 셰이더**: PBR 대신 명암을 뚜렷한 단계로 나누는 카툰풍 셰이더로 원본 Stack의 깔끔한 룩을 재현 (`Assets/Shaders/ToonNPR.shader`).
- **OKLCH 기반 색 그라데이션**: 층이 쌓일수록 색상각이 아주 천천히 순환하고 명도가 오르내리며 층별로 뚜렷이 구분되는 팔레트 (`OklchColor`).
- **우주정거장풍 상/하단 캡**: 허브+스포크+림 구조의 거대한 바퀴 모양 덮개로 시작/종료 지점을 장식 (`WheelCapBuilder`).
- **아이소메트릭 카메라**: 원근 왜곡 없는 오소그래픽 시점으로 원본 Stack의 카메라 느낌을 유지, 게임오버 시에는 타워 높이/화면비에 맞춰 자동으로 줌아웃해 잘리지 않게 전체를 보여줍니다.
- **시작 화면**: 최초 실행 시 타이틀 + 반투명 시작 버튼을 플레이 화면 위에 오버레이로 띄우고, 시작을 누르면 그대로 이어서 플레이. 게임오버 후 재시작할 때는 다시 뜨지 않습니다.
- **정렬 가이드**: 낙하 중인 링과 마지막 층 사이에 반투명 경계선을 표시해 정렬을 가늠하기 쉽게 하며, 온오프 토글 및 설정 저장(PlayerPrefs) 지원.

## 실행 방법

1. Unity Hub에서 이 프로젝트를 엽니다 (Unity 6000.3.21f1, URP).
2. 메뉴 `Tools > Gear Ring Stack > Build Scene` 실행 — 씬/카메라/조명/타워/UI/게임 매니저가 전부 연결된 플레이 가능한 씬(`Assets/Scenes/GearRingStack.unity`)이 자동으로 생성됩니다.
3. Play 버튼을 눌러 실행 — 화면을 탭(마우스 클릭/터치)하면 회전 중인 링이 멈춰 쌓입니다.

```
├── RingSlotUtil.cs           # 720슬롯 각도 배열 기반 판정 로직 (이빨 패턴, 회전, AND, 퍼펙트 비교)
├── GearRingMeshBuilder.cs    # 슬롯 패턴 → 절차적 3D 메시 변환
├── WheelCapBuilder.cs        # 허브+스포크+림 우주정거장풍 덮개 메시 빌더
├── OklchColor.cs             # OKLCH → RGB 변환 유틸
├── FallingRing.cs            # 낙하 링의 회전 + 탭 시점 논리 패턴 계산
├── TowerManager.cs           # 층 판정/누적, 난이도 곡선, 게임오버, 이펙트
├── GameManager.cs            # 입력 처리, 상태 전이(시작 대기/플레이/게임오버), 콤보
├── CameraRig.cs              # 아이소메트릭 추적 카메라 + 게임오버 리빌
├── UI/                       # HUD, 게임오버 화면, 시작 화면, 전체화면 탭 캐처
└── Editor/
    └── GearRingStackSceneBuilder.cs   # 씬 전체를 코드로 자동 생성하는 에디터 툴

기획서/
├── 기어링스택_게임기획서.md   # 최초 기획 문서
├── gear_ring_stack_mockup.html
└── 작업진행.md                # 세션별 작업 로그 (버그 수정 히스토리, 다음 할 일)
```

## 기술 스택

- Unity 6000.3.21f1 / Universal Render Pipeline (URP)
- 새 Input System (마우스/터치 통합)
- 커스텀 HLSL 셰이더 (Toon/NPR, 반투명 가이드 라인용 Unlit)
- 절차적 메시 생성 (MeshFilter/MeshRenderer 직접 조작, 별도 모델링 툴 없음)
