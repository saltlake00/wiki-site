# Unity 2D 플랫포머 - 타일맵, 스프라이트 애니메이션, 시네머신

2D 플랫포머를 만들면서 배운 내용 정리. 스프라이트 애니메이션부터 타일맵, 시네머신 카메라, 조작감 기능까지.

## 스프라이트 애니메이션

- 3D는 모델의 트랜스폼을 바꿔서 애니메이션을 만들지만, 2D 이미지는 그렇게 만들 수 없습니다.
- **등록된 스프라이트를 순서대로 변경하는 과정**으로 애니메이션을 만듭니다.
- 스프라이트 위치에 카메라에서 어떤 순서로 그려줄지 정하는 **정렬(순서)** 을 씁니다.

## 정렬: Sorting Layer / Order in Layer

레이어를 만들어서 그려지는 순서를 분리합니다.

- **Sorting Layer**: 내가 정한 카테고리. 이름을 정합니다.
- **Order in Layer**: 그 카테고리 안에서의 순서.

**우선순위**: Sorting Layer가 먼저 적용되고, 그 카테고리 안에서 Order in Layer가 적용됩니다.

스프라이트 두 개를 넣었을 때 **아래에 있는 게 더 가깝게(앞에) 보였습니다.**

## 타일맵

### Rule Tile (룰 타일)

- 어디에 붙을지, 어디에 붙지 않을지 **규칙을 정해서 그려주는 타일**.
- "이 블록 옆에는 어떤 블록이 와야 하는지" 규칙을 정합니다.
- 팔레트에 타일을 설정해서 저장해놓고 사용합니다.
- **Override Tile**: 룰 타일에서 정한 룰을 그대로 가져와서 씁니다.
- **Advanced Rule Override Tile**: 반대로 **그림만 그대로 사용하고 룰을 바꾸고 싶을 때** 씁니다.

### Animation Tile (애니메이션 타일)

- 타일은 정확히 그리드에 붙으니까, 타일이 애니메이션으로 포함되면 좋을 때 편리합니다.
- 애니메이션 만들 때 여러 스프라이트를 엮듯이, 애니메이션 타일을 생성하면 인스펙터에 **몇 개의 이미지를 넣을지 선택하는 타일**이 나옵니다.
- 타일을 여러 개 넣어놓으면 그 사이들이 돌아가면서 베리에이션처럼 작동합니다.

### 브러쉬 (Brush)

- **Line Brush**: 한 곳 찍고 다음 곳 찍으면 그 사이를 채워주는 브러쉬. 드래그로 여러 칸 찍으면 빈칸이 떨어집니다.
- **Random Brush**: 타일을 여러 개 등록해놓고 찍으면 그 중 랜덤하게 나옵니다.
- **Object Brush**: 이미지 타일 말고 실제로 만든 오브젝트(프리팹)를 타일에 등록해놓고 찍으면 오브젝트도 찍을 수 있습니다.

## 시네머신 (Cinemachine)

카메라 기능. 편하게 카메라를 설정할 수 있습니다.

- 카메라를 여러 대 만들 수 있고, **레이어 필터링**으로 미니맵(모델만 비추는 카메라) 등을 만들 수 있습니다.
- 카메라가 화면을 찍고 녹화하면 **렌더링 파이프라인 부하**가 늘어납니다 → **보여줄 카메라만 켭니다**.
- **Cinemachine Brain**: 가상 카메라(virtual camera)들을 배치해놓고, brain이 **어떤 카메라를 쓸지 결정**합니다. 실제로 동작하는 건 하나. 중앙 관리 체제.
- **Follow**: 카메라가 캐릭터를 따라옵니다. Tracking Target에 플레이어를 넣습니다.
- **카메라 크기 조절**: 시네머신 카메라의 렌즈(orthographic size)를 줄이고 키우면 씬에 표시된 카메라 범위가 보입니다.
- **Dead Zone (뱀핑)**: 얼마나 민감하게 따라오는지 조절합니다.

### Confiner (카메라 제한)

- **수점 범위(dead zone)를 정해주고 범위 밖으로 카메라가 나가지 않도록** 합니다.
- 맵 끝까지 걸어가도 카메라가 벽에 붙어서 안 나갑니다.
- 설정: Add Extension → **CinemachineConfiner**.
- 범위 지정자로 **Polygon Collider / Box Collider / Composite Collider** 중 하나를 넣습니다.
- 맵이 박스 크기면 Box Collider, 타일맵 구조면 Composite Collider(타일맵 병합할 때 쓴 것).
- Collider에 **Is Trigger 체크** (박스에 튕겨서 캐릭터가 날아가면 안 되기 때문입니다).

## 콜라이더 종류

- **Polygon Collider**: 폴리곤 구조로 복잡한 콜라이더 모양.
- **Box Collider**: 박스 모양.
- **Composite Collider**: 여러 콜라이더를 병합. 타일맵 구조에 딱 맞게.

## Freeze Position / Rotation

Rigidbody의 포지션/회전을 아예 못 움직이게 막는 기능.

- **Z축 회전을 막으면** 캐릭터가 뱅글뱅글 돌아가는 상황을 막습니다.
- **Y축 회전을 막으면** 캐릭터가 뒤집히는(플립) 형상을 막습니다.

## 조작감: Coyote Time / Jump Buffering

- **Coyote Time (콜트 타임)**: 캐릭터가 낙하 중에 발이 땅에 안 닿았는데 거의 닿았을 때, 잠깐 점프할 수 있는 기회를 주는 기능. 땅을 벗어난 직후에도 잠깐 점프 가능.
- **Jump Buffering**: 점프 입력을 미리 받아두는 기능.
- 유저의 조작감을 높이기 위한 기능들.
