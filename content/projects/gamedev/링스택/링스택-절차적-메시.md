# 링스택 절차적 메시

> **판단**: 이음매 틈을 구조적으로 없애려고 **이웃 각도 분할과 정점을 공유하는 진짜 쐐기** 지오메트리를 택했다. 단, **면과 면 사이는 하드 엣지로 분리해야** 카툰 셰이딩의 단계가 산다 — 정점을 더 공유하는 방향으로 "최적화"하면 안 된다.
> **다음**: 없음 — 노멀 와인딩 버그까지 잡혀 안정. `status: stable`로 내릴 후보.

슬롯 패턴을 3D 메시로 변환하는 절차적 지오메트리 생성.

## 핵심 설계

- **진짜 쐐기(부채꼴) 지오메트리**: 이웃한 각도 분할과 정점을 공유 → 이음매(삼각형 틈/겹침)가 구조적으로 발생하지 않음.
- **하드 엣지 유지**: 면마다 독립된 정점 스트립(`AddWallStrip`/`AddCapStrip`)으로 분리 → 같은 면 안의 이웃 분할끼리만 정점 공유, 면과 면 사이는 하드 엣지로 확실히 분리.
- **노멀 와인딩**: 윗면은 항상 +Y, 아랫면은 항상 -Y 노멀. (이전에 뒤바뀌어 있던 근본 버그 수정됨)

## 구현 파일

- `GearRingMeshBuilder.cs` — 슬롯 패턴 → 절차적 3D 메시 변환
- `WheelCapBuilder.cs` — 허브+스포크+림 우주정거장풍 덮개 메시 빌더
