# 링스택 색상 팔레트

OKLCH 기반 층별 색 그라데이션 시스템.

## OKLCH 색상 모델

- `OklchColor.cs` — OKLCH(명도/채도/색상각) → Unity sRGB Color 변환 유틸 (Ottosson 공식).
- 이후 모든 팔레트를 여기서 만든 색으로 통일.

## 층별 그라데이션

- 층이 쌓일수록 색상각이 아주 천천히 순환하고 명도가 오르내리며 층별로 뚜렷이 구분되는 팔레트.
- **색상각 순환**: 층마다 색상각을 계속 증가시키는 단순 순환 방식 (15층마다 색상환 한 바퀴).
- **명도 위주**: 하나의 톤이 아주 오래 유지되게 하고, 명도를 사인파로 오르내려 밝음/어두움 밴딩으로 그라데이션 표현.
